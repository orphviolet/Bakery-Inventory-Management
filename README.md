# Bakery Inventory Management System

Sistem manajemen stok untuk toko roti. Ada dashboard ringkasan data roti dan bahan baku, kelola data roti (kode, nama, tanggal kedaluwarsa, stok), barang masuk, barang keluar, dan bahan baku dengan fitur cari/filter, plus riwayat keluar-masuk stok dan halaman profil.
